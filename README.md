# 🚀 Featured Projects

## 🔥 LD Steelmaking Computer Vision

Computer vision and data acquisition system developed for monitoring experiments in an **LD steelmaking pilot plant**.

The system processes images captured by multiple cameras to detect and quantify projection patterns during experiments. The extracted visual information is integrated with operational process data for further statistical analysis.

The project includes video conversion, automatic frame extraction, OCR-based timestamp recognition, background subtraction, image segmentation, region-based measurements and data consolidation.

**Technologies:**

`Python` `OpenCV` `Tesseract OCR` `PaddleOCR` `NumPy` `Pandas` `Matplotlib` `FFmpeg` `Computer Vision` `Image Processing`
